— The workflow —

Every class, a little easier.

Pick a path to see how SnapClass fits your classroom.

STEP 01 • GET STARTED

Secure login

Sign in with a username and password, or register to create a teacher account. Passwords are protected with bcrypt.

STEP 02 • SET UP CLASS

Create a subject

Add a subject name, code, and section, then share the code with students so they can enroll.

STEP 03 • TAKE ATTENDANCE

Capture the classroom

Choose a subject, add classroom photos, or take attendance with voice.

STEP 04 • LET AI CHECK

Run face analysis

SnapClass scans the submitted photos and marks enrolled students present or absent.
